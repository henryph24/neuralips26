**Response to the Area Chair**

We are grateful to the AC for the careful synthesis and the explicit prioritization, which made this response far more focused, and to all three reviewers for engaged and constructive reviews. Several experiments below exist because of their questions. Full detail is in the individual responses; `[NEW]` marks rebuttal-phase work.

**3 (task diversity).** The routing signal is the raw input window, so it does not change with the objective. `[NEW]` RR-MoA on three UEA classification datasets and a reconstruction-based anomaly check on SMD (3 seeds each) keep routing entropy healthy in every cell (1.46-1.59 and 1.52-1.61; log 5 ≈ 1.61 ceiling, 0.00 floor). Frozen features cap absolute accuracy, so we scope both as mechanism-generalization. With imputation (7/8) that is four task types. `[NEW]` An input-length ablation (72 runs) shows no collapse at any L, and `[NEW]` H∈{1000,2000} extends past the paper's 720 (per-seed tables in our reply to Reviewer jemj).

**4 (frozen backbone).** We recommend freezing as the default, and we show the method holds without it: Table 1 has RR-MoA beating the best fixed adapter with Last-2 and Last-4 unfrozen as well as frozen (ETTh1 -44% / -29% / -32%), with frozen strongest on 4/6. We also read freezing as a deployment advantage, and we set that out in our reply to Reviewer jemj.

**5 (memory).** We lower router memory by routing on the raw input. We read one univariate window (~0.26 MB at B=128, L=512), about 64× smaller than the hidden states a conventional router reads, and we re-read the model's own input, so we allocate nothing new. We keep the backbone frozen, so it carries no gradients or optimizer state and training peak memory sits at the usual frozen-adapter floor. At inference we add at most +5.9% latency and +6 MB for the 853-parameter gate and the experts.

**6 (scope of the theory).** We account for what normalization destroys (Observation 1, recast as rate-distortion in App. D.1), how collapse unfolds (Proposition 1), when it onsets (Proposition 2, α*≈R(D)/(R(D)+1)), and which datasets are vulnerable before any training (R(D), ρ=-0.88). We agree that dataset-specific structure and feature asymmetry remain open, and we find that direction genuinely valuable.

**7 (expert scaling).** The concern is fair for a standard MoE, whose router input grows with K; ours does not. The router input is a fixed-size raw window, identical at K=5 and K=20, and Top-2 runs two experts per sample at any K, so compute and bandwidth stay at O(2). `[NEW]` Extending Table I.3 to K=15 and K=20: MSE stable, entropy at 91-97% of its log K ceiling, still ~40% better than best-fixed.

**8 (intervention beyond IN).** App. H swaps RevIN for BatchNorm1d (0.62→0.004) and GroupNorm (0.51→0.000), which collapse identically, with the no-norm control healthy (0.82); `[NEW]` a LayerNorm at the same input position collapses too (→0.000). Encoder-internal LayerNorm and RMSNorm (Chronos, Timer-XL) do not, since they never strip the router's input: the rule is positional, not normalizer-specific. App. H.1 replicates it in vision, and AdaMix-Raw isolates it most sharply: swapping only an existing MoE's router input recovers entropy 0.49→1.55.
